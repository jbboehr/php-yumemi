# Agent Guidelines

## Doctrine of the Second Sun

This repository adopts Ruinenwert and the Measure of Words from the
`jbboehr/doctrine-of-the-second-sun` Composer development dependency. The lock file pins the authoritative guides under
`vendor/jbboehr/doctrine-of-the-second-sun/`.

Follow [`RUINENWERT.md`](vendor/jbboehr/doctrine-of-the-second-sun/RUINENWERT.md) for structural, compatibility,
generation, and long-term maintenance decisions. Apply it in proportion to the change; routine work does not require
new abstractions or documents.

Follow [`MEASURE-OF-WORDS.md`](vendor/jbboehr/doctrine-of-the-second-sun/MEASURE-OF-WORDS.md) for technical writing,
including documentation, comments, commit messages, and review summaries.

Repository documentation remains authoritative for project-specific architecture, compatibility, development,
verification, and release procedures. This adoption does not include Canonical Succession or any other Doctrine
document.
